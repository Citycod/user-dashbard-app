📱 CityTopUp User Dashboard
CityTopUp is a modern VTU (Virtual Top-Up) platform that allows users to purchase airtime, data bundles, and pay utility bills with ease. This User Dashboard is a secure and interactive interface where registered users can manage their accounts, view transaction history, and perform top-ups efficiently.

✨ Features
🔐 Secure User Login & Authentication

📊 Dashboard Overview with Balance & Recent Transactions

📱 Airtime and Data Purchase (MTN, Airtel, Glo, 9mobile)

💡 Utility Bill Payments (Electricity, Cable TV, etc.)

💼 Wallet Funding & Transaction History

🔔 Real-time Notifications

⚙️ User Profile Management

🌓 Modern UI with Light/Dark Mode (optional)

🎯 Scroll Animations using AOS for smooth UI effects

🛠️ Tech Stack
Frontend: HTML, CSS (Bootstrap 5 / Tailwind CSS), JavaScript

Backend: PHP / Node.js (based on your stack)

Database: MySQL

Libraries/Tools: AOS (Animate On Scroll), FontAwesome, jQuery
